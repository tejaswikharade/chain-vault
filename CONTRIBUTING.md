# Contributing

ChainVault is an educational Solidity project. Small, focused improvements are welcome.

## Before opening a pull request

1. Keep the contract interface and event semantics clear and documented.
2. Add or update a Foundry test for behavior changes.
3. Run `forge test` and `npm run build` from `frontend/` when those tools are available.
4. Do not submit private keys, deployed addresses with value, or production custody claims.

## Scope

Please treat this repository as a learning implementation, not audited custody software. Security-focused issues and pull requests that explain their threat model are especially useful.
